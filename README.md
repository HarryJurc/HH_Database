"# HH_Database"
Проект для получения данных о работодателях и вакансиях с сайта [hh.ru](https://hh.ru) с сохранением в PostgreSQL и возможностью анализа через CLI.

## Возможности
- Получение данных о компаниях и вакансиях через API hh.ru
- Хранение данных в PostgreSQL
- Анализ вакансий: средняя зарплата, фильтрация по ключевым словам
- Удобный интерфейс командной строки

## Установка
```bash
git clone https://github.com/your-username/hh-parser.git
cd hh-parser
pip install -r requirements.txt

## Настройка файла .env
DB_NAME=hh_vacancies
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
BASE_URL=https://api.hh.ru/vacancies

## Использование
python main.py


## Функциональность

1. **Показать компании и количество вакансий** — выводит список всех компаний и количество вакансий для каждой.
2. **Показать все вакансии** — выводит список всех вакансий с указанием названия компании, названия вакансии, зарплаты и ссылки.
3. **Показать среднюю зарплату** — вычисляет и выводит среднюю зарплату по всем вакансиям.
4. **Вакансии с зарплатой выше средней** — выводит вакансии с зарплатой выше средней.
5. **Поиск вакансий по ключевому слову** — позволяет искать вакансии по ключевому слову в названии.

## Структура базы данных

Проект использует две таблицы:
- **employers** — информация о работодателях (ID, название, ссылка).
- **vacancies** — информация о вакансиях (ID, название вакансии, зарплата, ссылка).

## Используемые технологии

- Python 3.x
- requests — для работы с API HH.ru
- psycopg2 — для работы с PostgreSQL
- dotenv — для работы с переменными окружения
